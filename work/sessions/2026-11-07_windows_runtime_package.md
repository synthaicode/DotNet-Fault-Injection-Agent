# 2026-11-07: Bundled Windows execution payload

Changed the NuGet tool from planning-only distribution to include an exportable win-x64 Engine, Rewrite extension/XML, PowerShell launcher, checksums and license notices. `runtime list` discovers the payload and `runtime export --output <new-directory>` verifies checksums before export and refuses an existing destination. No process starts and no service is registered during installation/export.

Built Engine from unmodified MIT-licensed CLRInstrumentationEngine revision 0055c6fce2fe16770f5908ef14cfd7f8a42c2fab, rather than redistributing a Visual Studio installation DLL. Build settings: Release x64, SignType=None, SpectreMitigation=false. Restored upstream native build packages and rebuilt this repository's extension. Included Engine LICENSE/THIRD-PARTY-NOTICES, nlohmann/json 3.11.3 MIT notice and project MIT license. Inspected both native DLL imports: only Windows system DLL dependencies were listed; no external VC runtime dependency was listed.

Validation used an isolated local NuGet feed and empty cache. Confirmed payload entries, install, guide/help, runtime discovery, checksum-verified export, no-overwrite behavior and plan generation/verification. Built fresh Framework SqlTarget and .NET CoreFileTarget fixtures, generated/verified file-write plans using the installed CLI and executed only the exported launcher/runtime. Both recorded acceptance/rewrite, exactly one IOException firing, successful later file creation, zero exit and unchanged target hash. Additional exploratory exported-runtime trials passed fixed return rewrite, CoreFileTarget, Framework file failure and SQL timeout.

Evidence is under [windows-runtime-package](2026-11-07_windows-runtime-package/package-summary.json), with fixture results and the native payload manifest beside it. Fixture builds are maintainer verification, not a user requirement. Current delivery scope is Windows x64 dedicated fixtures/order host. Linux generic planning remains available but Linux execution assets are not bundled. This phase did not repeat VM service tests and did not publish to NuGet.org.
